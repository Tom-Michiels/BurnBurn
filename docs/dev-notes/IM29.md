# IM29 Machinebeheer en calibratie — softwaredeel

Status: groen op macOS arm64 (softwaredeel). Geen controllercommando's voor bestanden of instellingen op de wire: er is
geen geverifieerde registermap of bestandsprocedure; alle capabilities starten `Unverified` (= `Unsupported`).

Commando's: `export PATH="$HOME/.cargo/bin:$PATH"; CARGO_TARGET_DIR=target/protocol cargo test -p burnburn-machine
--test calibration|management`, `-p burnburn-history --test calibration|settings`, `-p burnburn-runtime --test usb`.

## API (kort)
- `burnburn_machine::calibration`: `CalibrationSet { kerf_mm: BTreeMap<MaterialKey, f64>, scan_offset: Vec<ScanOffsetPoint>,
  pointer_offset_mm }`, `CalibratedProfile::new(MachineProfile, CalibrationSet)` → setup-`ProfileRevision` (content =
  hash over profielcontent + alle calibratiewaarden, domein `profile`), `with_calibration`, `is_current_for`.
  Validatie: eindig, kerf ≥ 0, snelheid > 0, één punt per snelheid (`DuplicateSpeed`).
- Proefpatronen als gewone `JobPlan`s: `pointer_offset_plan` (kruis), `scan_offset_plan` (per snelheid een blok
  bidirectionele scanrijen), `kerf_test_plan` (rij vierkanten van nominale maat); elk punt binnen het bed, anders
  `OutsideBed`; plan-bron = hash van de proefparameters.
- `controller_files`: `Capability::{Supported, Unsupported, Unverified{reason}}`, `FileCapabilities` (default alles
  `Unverified`), `ControllerFileName` (printbare ASCII, geen NUL), `ControllerFileIntent::{List, Upload, Delete}`,
  `authorize(&intent, &caps)`.
- `settings`: `SettingKey`, `SettingValue::{Bool, Integer, Micrometres, Text, Raw}`, `ControllerSettingsSnapshot`,
  `diff(a, b)` (gesorteerd, alleen verschillen).
- `burnburn_history::SettingsBackup` (JSON, schema 1): getypeerde waarden; onbekende waardetypes en onbekende
  topvelden blijven letterlijk behouden; `History::record_settings_backup` / `settings_backups(machine)`.
- USB: `burnburn_runtime::{UsbConfig, UsbPort}`; `UsbPort::open` → `PortError::NotSupported(USB_NOT_SUPPORTED)`.

## Afwijkingen (ter review Design)
- Calibratiepatronen staan in `burnburn_machine::calibration`, niet in `cam::calibration` (andere eigenaar).
- `CalibrationSet` zit niet in `job::MachineProfile` (CAM); de setup-revisie wordt in `CalibratedProfile` berekend en is
  wat `CompiledJob.profile` vastlegt. Toepassen van scan-offset/kerf bij compile/lower bestaat nog niet (CAM/lower).
- `ControllerSettingsSnapshot` heeft geen `read_at`; de wandtijd staat in `SettingsBackup` (history), omdat machine geen
  wandklok kent.

## Open / onbevestigd

- USB: alleen poortdefinitie; geen VID/PID, endpoints of framing.
