# IM06 AppKit-host in Rust (`burnburn-macos`) — eerste ronde

Status: minimale host werkt op macOS 27 arm64: venster, splitview (objectlijst-placeholder | canvas-NSView |
inspecteur met `NSTextField` "Breedte (mm)"), hoofdmenu (Archief › Bewaar ⌘S, Wijzig › Herstel ⌘Z / Opnieuw ⇧⌘Z),
wgpu-Metal-surface op de canvas-view. De plan-eindtest `native_dimension_commit_dispatches_one_document_command`
wacht op `burnburn-presentation`; nu eindigt de keten op een `IntentSink` (overdracht: `docs/coordination/gui.md`).

## Opbouw
- `src/adapter.rs` — zonder AppKit: `NativeEvent` → `UiIntent` (`CommitDimension { width_mm }`, `Undo`, `Redo`, `Save`),
  `FieldStatus` voor parsefouten, `HostAdapter::close()` → daarna geen intents. Headless getest (ook op Windows/Linux).
- `src/appkit/` — dunne objc2-laag (`unsafe` alleen hier, ADR 0002): `controller.rs` (`define_class!`
  `BurnBurnWindowController`: target van veld en menu, window-delegate), `canvas.rs` (surface), `mod.rs` (venster/menu).
- `tests/native/macos/*.rs` — `harness = false`, eigen `main` op de hoofdthread, echte eventloop, één scenario per proces.

### Bevinding (canvas, geen wgpu-bug)
wgpu-hal 30 slaat `nextDrawable` over als `NSWindow.occlusionState` geen `Visible` (1<<1) bevat. Een testproces kan
de focus niet van de voorste app van de gebruiker afnemen; het venster lag werkelijk achter een ander venster
(`occlusionState` = 8192, zonder bit 1). Oplossing: (1) de host tekent opnieuw bij `windowDidChangeOcclusionState:`
(naast resize en backing-scale-wijziging) en behandelt `Occluded` als "later"; (2) de native tests zetten het venster op
`NSFloatingWindowLevel` + `orderFrontRegardless`. Daarna `occlusionState` = 8194 en ≥ 1 frame gepresenteerd.

- `cargo test -p burnburn-render -p burnburn-macos --locked` → adapter 6 passed; native: 3 processen elk `1 passed`.
- `cargo clippy -p burnburn-render -p burnburn-macos --all-targets --locked -- -D warnings` → schoon (met ADR-0002-lints
  `undocumented_unsafe_blocks`, `multiple_unsafe_ops_per_block`, `unsafe_op_in_unsafe_fn`).

  native_canvas_surface`, intern `screencapture -x -o -l <windownummer>`): drie panelen, grijze rechthoek 120×80 mm met
  blauwe selectierand in het Metal-canvas, veld "120". Visueel beoordeeld; geen geautomatiseerde pixelcheck op het scherm.
- `target/gui/debug/burnburn` (zelfde binary als `cargo run -p burnburn-macos`) 3 s gestart en gestopt: proces liep,
  canvas-surface aangemaakt; venster lag achter de voorste app (Occluded), dus het beeld van de binary zelf is **niet**
  visueel bevestigd. Graag handmatig: `cargo run -p burnburn-macos`, venster verschijnt, ⌘Z/⇧⌘Z/⌘S loggen een intent,
  sluiten beëindigt de app.

## Onbevestigd / open

  Return + focusverlies?), menuvalidatie, NSUndoManager-spiegeling, open/save-panelen, multi-window (menu-target is nu het ene venster).

- Minimale macOS-versie (ADR 0002 open).

# Fase B (18-10-2026) — host gekoppeld aan `burnburn-presentation::AppController`

## Opbouw (nieuw)
- `src/adapter.rs` (zonder AppKit, headless getest): `NativeEvent` (platte data) → `Reaction` (`UiIntent` van
  presentation of `ShowOpenPanel`). Ruwe veldtekst naar `UiIntent::CommitField` (DR-05; host-parser + tests verwijderd,
  `presentation::parse_length` is de enige parser). Ongewijzigde veldtekst = geen intent (Return + Tab = één command).
  Menu: tag ↔ `MenuItem` (Open + alle `CommandKey::ALL`), `menu_enabled/menu_checked/menu_title` uit `vm.commands`.
  Sluitsheet-knoppen Bewaar/Annuleer/Niet bewaren → `CloseChoice` (onbekend = Annuleer). Muis (flipped view, punten,
  Ctrl-klik = secundair), scroll/pinch/resize → `UiIntent::Camera`, Esc/⌫/Del/Return → `UiIntent::Key`. NL-teksten.
- `src/tasks.rs`: `ThreadTaskPort` (thread per taak, productie-`run_task`) + `TaskInbox`; wake-up via
  `dispatch2` main queue → `HostApp::drain_tasks` → `AppController::task_finished`.
- `src/appkit/`: `app.rs` (`HostApp`: één controller, vensters per document, effecten na het loslaten van de borrow),
  `window.rs` (split view: `NSTableView` objectlijst | canvas | inspector met 2 velden + statusregel), `classes.rs`
  (`MenuTarget` met `validateMenuItem:`, `WindowController` = window delegate + veld-target + table data source/delegate,
  `CanvasView` flipped NSView-subklasse), `canvas.rs` (Metal-factory voor `render::surface::SurfaceCanvas`).
  Sluiten: `windowShouldClose:` → `Close` → presentation; dirty → `NSAlert`-sheet. NSSavePanel als sheet, NSOpenPanel
  modeless. App: `StdFileSystem` (bestanden via de gebruiker gekozen pad); tests: alleen een verse map onder `$TMPDIR`.
- `cargo xtask bundle [--release]` (`xtask/src/bundle.rs`): unsigned `BurnBurn.app`, Info.plist met
  `CFBundleDocumentTypes` (`app.burnburn.project`, Owner/Editor), `UTExportedTypeDeclarations` (`.burnburn`,
  `public.zip-archive`), `LSMinimumSystemVersion` 13.0; binary gebouwd met `MACOSX_DEPLOYMENT_TARGET=13.0`.

# Vervolg fase C (18-10-2026) — host verder uitgebouwd (details in `IM20.md`, camera in `IM27.md`)

- Adapter: teksten komen uit `burnburn_macos::l10n` (`menu_title(item, vm, locale)`, `message_text(key, locale)`);
  de NL-tabellen in `adapter.rs` zijn weg. Nieuwe events: `ToolChosen`, `PanelCommand`, `ExportPanelFinished`,
  `TextCommitted` (→ geen intent), `ImportFileChosen`, `ImportUnitChosen`; `MenuItem::Import` → `ShowImportPanel`.
  Bestaande adaptertests aangepast met `Locale::Nl` (zelfde verwachte teksten).
- `WindowParts::{width_field,height_field}` vervangen door `fields` + `field(FieldKey)`; drie native tests aangepast.
- `HostOptions` kreeg `locale` en `terminate_on_quit`; `common::start()` kiest NL expliciet (tests hangen niet af van
  de taal van de machine), `common::start_with`, `become_key`, `click_close_alert`, `wait_close_alert`.
- Windows-host (IM08): `burnburn_windows::l10n` = hetzelfde bronbestand (`#[path]`); `message_text(key, locale)`
  met `GetUserDefaultLocaleName`. Test `message_texts_come_from_the_shared_catalogue`: red
  `cargo test -p burnburn-windows --test adapter` → 1 failed (EN gaf NL), green → 13 passed. Clippy
  `result_large_err` (UiIntent groeide bij User-flow) opgelost: `commit` geeft `Option<UiIntent>`.
  `cargo check`/`clippy --target x86_64-pc-windows-msvc -p burnburn-windows` schoon — typecheck, **onbevestigd** op Windows.
