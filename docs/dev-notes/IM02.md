# IM02 Eenheden en geometrie

Status: gereed (macOS arm64, headless). Windows: onbevestigd (geen runner).

## Opgeleverd
- `burnburn-types`: `Unit` (mm/inch, exact 25.4), `Length::new/to_unit`, `Angle` (finite, radialen),
  `RevisionId` (strikt stijgend, `next() -> Option`; aanvankelijk `checked_next`, hernoemd conform `docs/design/contracts.md`), `StableId` + `GeometryId`/`OperationId`, deterministische
  `IdAllocator` (één teller voor alle soorten, `resume_at` na laden, `IdExhausted`).
- `burnburn-geometry` (nieuw, laag 1): `Point`/`Vector` (`f64`, mm, y-up), `Affine` (finite, `then`, `inverse` →
  `GeometryError::Singular`), `Bounds`, `Rect`, `Segment::{Line, Cubic, Arc}`, `EllipticalArc` (geconjugeerde halve
  diameters, exact onder affine), `Path`/`Subpath`/`PathBuilder` met meerdere subpaden, `signed_area`, `Winding`,
  exacte curve-bounds, `flatten` en drie losse tolerantietypen (`DisplayTolerance`, `ProductionTolerance`,
  `HitTestTolerance`; alleen de eerste twee implementeren `FlatteningTolerance`).

## Numerieke afspraken
- Testgrenzen zijn per test onderbouwd (`EPS_MM = 1e-12` voor exacte conversie, `1e-9` voor rondreis via twee
  matrixproducten bij ~1e3 mm). Geen globale epsilon.
- `SINGULAR_RELATIVE_DET = 1e-12` (relatief aan max-coëfficiënt²) en `ARC_CONTINUITY_MM = 1e-9` zijn structurele
  float-ruisgrenzen, geen gebruikerstoleranties.
- Flatteninglimieten: max. subdivisiediepte 24 per cubic, max. 2^20 koorden per arc (begrensde uitvoer).
