## Afwijkingen / open
- **Schema:** opdracht vroeg een schema-bump; Design C-3 (bindend) zegt "additief in schema 2 tot de eerste release".
  Gevolgd: geen bump, oude bestanden (v1-, v2-fixture) laden ongewijzigd.
- Relaties worden **gecontroleerd** (residu), niet afgedwongen; afdwingen via de sketch-solver vraagt een extern-entiteit
  in het sketchcontract (vraag in `docs/coordination/sketch.md`).
- Herkomst-matching is O(uit × in) per stap; geen benchmark. Booleans/offsets polygonaal (i_overlay).
- Referenties naar getekende objecten blijven gebonden zolang de `EdgeKey` bestaat; structuurwijzigende edits behalve
  Insert/Reverse/Convert geven conservatief nieuwe sleutels (breken liever dan herbinden).
- `ApplyPatch` voor sketch-owners → `InvalidPatch` (document kan sketch-inputs niet berekenen); Trace (C-9) breidt uit.
- Varianten met andere topologie: ondersteund via shapesleutels; refs naar verdwenen shapes → `Broken`.
