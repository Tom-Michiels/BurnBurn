# IM23 Centerline en technische reconstructie

Status: groen op macOS arm64, headless. Windows: onbevestigd (geen runner).
Rol: Implementatie (beeld/trace). Crate: `burnburn-trace`, module `centerline` (`skeleton`, `graph`, `primitive`).

## Opgeleverd
- `trace_centerline(&CenterlineRequest, &CancellationToken)` → `CenterlineResult` (eigen inputs-sleutel
  `CenterlineRequest::key()`, `check_fresh` zoals DR-14, engine `burnburn-trace/centerline-1`).
- Keten: `prepare` → Zhang–Suen-verdunning (eigen implementatie, CACM 1984) → graaf. Knoopclassificatie op
  **effectieve graad** (4-buren + diagonalen die niet al via een gedeelde 4-buur bereikbaar zijn): ≤ 1 eind, 2 keten,
  ≥ 3 junctie; aangrenzende junctiepixels vormen één knoop. Ketens worden gelopen met 4-buren eerst.
- Spurcontrole: tak eind↔junctie korter dan `max(min_spur_mm, spur_width_factor · breedte)` wordt verwijderd en
  gemeld (`spurs_removed`); takken binnen 1 px van `keep_spurs_near_px` blijven. Graad-2-knopen verdwijnen.
- Junctieverfijning: kleinstekwadraten-snijpunt van de taklijnen (punten 1–3 breedtes van de knoop), alleen
  geaccepteerd binnen één breedte. Junctiesamenvoeging: korte verbindingsketen óf verfijnde posities binnen een
  halve breedte → één knoop (bijv. X onder 40°).
- Breedte (mm) per knoop/keten uit een exacte Euclidische afstandstransformatie (Felzenszwalb–Huttenlocher);
  metadata, nooit reden om dubbel te snijden.
- Verbindingen: elke junctie is `Connections::Ambiguous { candidates }` (alle maximale paringen t/m graad 6,
  gesorteerd op afwijking van rechtdoor); pas `resolve_junction` maakt `Resolved`. `strokes()` loopt alleen door
  `Resolved`-knopen: er wordt geen continuïteit verzonnen.
- `near_contacts`: componenten waarvan de randen dichter dan `near_contact_factor · breedte` liggen (blijven gescheiden,
  plek + spleet in mm gemeld). Versmolten streken leveren altijd ambigue juncties.
- Lokale split/join: `resolve_junction` (paren kiezen = splitsen/verbinden door een junctie), `join_endpoints`
  (reparatieketen `ChainOrigin::Repair`, maximaal `max_join_factor · breedte`, anders `TooFar`).
- Kandidaten per keten (`primitive`): TLS-lijn, Kåsa-cirkel + Gauss–Newton, boog (afgewikkelde hoek ≥ 0,17 rad),
  cirkel bij gesloten keten; met max- en rms-residu en `within_tolerance`. Bevestigde vervanging:
  `propose_replacement` (lijn vóór cirkel vóór boog, binnen tolerantie, anders `NoCandidate`) →
  `confirm_replacement` (weigert met `Stale` als het resultaat sindsdien is bewerkt) → exacte primitive in het pad.
  Zonder bevestiging blijft de vrije geometrie (geen `Arc`-segmenten).

## Onbevestigd / open
- Windows-run; prestaties op grote beelden (near-contacts is O(randpixels²) per componentpaar binnen bbox).
- X onder 20–30°: twee ambigue juncties (lange overlap), geen samenvoeging — bewust, de mens beslist.
- Technische reconstructie naar een echte Sketch (S08/T08 "maakt echte primitives") hoort bij Sketch/User-flow:
  `Primitive` is de overdracht; AutoConstrain-voorstellen zijn niet in deze crate.
