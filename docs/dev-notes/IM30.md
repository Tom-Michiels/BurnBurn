# IM30 CLI, prestaties en uitbreidingsgrens (`burnburn-cli`)

Status: groen op macOS arm64. De CLI is een bibliotheek (`burnburn_cli::run(argv, &CliEnv)`) plus binary `burnburn`;
alle IO is geïnjecteerd (tests: `MemoryFileSystem`, `FakeClock`, `ScriptedPeer`-fake controller; geen socket).

Commando's: `export PATH="$HOME/.cargo/bin:$PATH"; CARGO_TARGET_DIR=target/protocol cargo test -p burnburn-cli`;
benchmark: `cargo test -p burnburn-cli --release --test bench -- --ignored --nocapture`.

## API (kort)
- `compile <project> --profile <p.json> --out <x.rd> [--plan-json <p>] [--history <dir>]`: laden → `presentation::run_task(
  TaskInput::Compile)` (zelfde functie als de GUI, zelfde opties: tolerantie 0,01 mm, absolute plaatsing, start bij
  machine-oorsprong) → preflight (fout = exit 2, niets geschreven) → `TaskInput::ExportRd` (atomair) → optioneel
  `CompiledJob` in de historie met exact de geschreven bytes. Weigert `--and-start`/`--upload`/`--start`.
- `inspect <x.rd> [--magic]`: decode-overzicht (records, bestandssom, travel/cut, onbekend/registered, cut-bounds in mm,
  snelheden, max power raw) met de melding dat labels geen firmwaresemantiek zijn.
- `preflight`, `history --history <d> [--project <hash>] [--machine <id>]` (jobs, executions met toestand en intents,
  queue-aantallen, torn tails / read-only).
- `upload … --allow-machine-contact` en `start --execution <n> … --allow-machine-contact`: gescheiden intenties via
  `MachineDriver`; zonder switch `MachineContactNotAllowed` (exit 2) en geen verbinding. `start` doet eerst identiteit +
  read-back (`reverify`) en start alleen bij vers `Stored`. Productie-connector weigert (`NoVerifiedDialect`), dus de
  binary contacteert nu nooit een machine.
- `plugin_manifest::validate_manifest`: `burnburn-plugin/1`, soorten generator/importer/exporter, `deny_unknown_fields`,
  machine- of netwerktoegang → geweigerd. Geen laden of starten van code.

## Afwijkingen
- De CLI gebruikt `run_task` direct, niet de `AppController` (contract §IM30); de compile-opties zijn gedupliceerd
  (`COMPILE_TOLERANCE_MM`), bewaakt door de pariteitstest. Verzoek aan User-flow: `compile_options()` publiek maken.
- Plugin-schema staat in `burnburn_cli::plugin_manifest` i.p.v. `burnburn-plugin-api` (nog geen crate in `layers.toml`).
- Geen `export`/`status`-subcommando (compile schrijft al RD; status heeft geen geverifieerde wire-vorm).

## Onbevestigd
- Upload/start op echte hardware: nooit uitgevoerd; productie weigert zonder geverifieerd dialect.
- Windows: niet gebouwd of getest.
