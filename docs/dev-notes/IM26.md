# IM26 Arrays en mixed-part nesting (rol CAM/job)

Status: eerste deel gereed op macOS arm64.

## Opgeleverd
- `burnburn_cam::{grid_array, circular_array}` (`GridArray`, `CircularArray{count, center, sweep_deg, rotate_items,
  reference}`) → `Vec<Affine>` (identiteit eerst; veelvouden van 90° exact). Generator, geen documentdata; koppeling als
  IM21-modifier ligt bij Kern (`cam.md`).
- `burnburn_cam::nest::nest(&[NestPart], &[Stock], &NestParams, &CancellationToken) -> Result<NestResult, NestError>`:
  bottom-left fill op een **conservatief bezettingsraster** (stap `step`): een onderdeel bezet elke cel waar zijn
  oppervlak in komt (open-celtest + celmiddens), een plaatcel is vrij als de gesloten cel in het bruikbare gebied ligt
  (plaat − gaten − keep-outs, ingekrompen met `edge_margin`), geplaatste delen blokkeren hun voetafdruk + `spacing`
  (Round-offset). Dus nooit overlap, afstanden ≥ spacing/marge (minus de koordetolerantie bij ronde hoeken).
  Volgorde: grootste netto-oppervlak, dan `PartKey`; rotaties alleen uit `RotationSet`, gefilterd op nerf
  (`part.grain + r ≡ stock.grain (mod 180°)`). `unplaced` per part met reden `NoFit | NoAllowedRotation | Budget`;
  `Utilisation { used_mm2, basis: StockArea | UsedBoundingBox, denominator_mm2, value }`. Deterministisch (geen
  random, geen hashmaps), budget `max_candidates`, annuleerbaar.

## W3-UI-schikken — Quick Nest en Nest Selected als paneel met annuleerbare taak (golf 3, C10)

`burnburn_cam::nest` plaatst delen op een plaat; het paneel maakt daar een bedienbare taak van. Delen = de objecten van
het gekozen bereik (Quick: alles wat beweegt; Selected: de selectie, groepen als één lichaam via `expand_to_groups`).
Open paden, afgeleide vormen (schets/tekst/array) en objecten zonder geometrie worden **overgeslagen en gerapporteerd**;
vergrendelde objecten blijven stil staan. Wat blijft staan en een gesloten omtrek heeft, wordt `keep_out` van de plaat
(Nest Selected ontwijkt de rest). Plaat = het machinebed (profiel) of, zonder machine, de omvang van de delen plus
randmarge + tussenruimte + één rasterstap. Opties: tussenruimte (padding), randmarge, rasterstap, rotaties (geen /
0°-180° / kwartslagen / 45°). `TaskInput::Nest` (`TaskKind::Nest`, revisiegevoelig: een bewerking annuleert de
lopende taak, een resultaat van een andere revisie wordt nooit genomen, een antwoord van een oudere taak-id wordt
genegeerd). Toepassen = `PlaceCommand::Nest { moves }` (nieuw in `document/src/edit/place.rs`, label `EditLabel::Nest`,
fout `EditError::DuplicateTarget`): elk object zijn eigen `Affine`, één transactie, één undo-stap. Rapport (C10): geplaatst,
niet geplaatst met reden (`NoFit | NoAllowedRotation | Budget`), overgeslagen met reden, benutting; "Kies
niet-geplaatste" selecteert de niet-geplaatste objecten.
