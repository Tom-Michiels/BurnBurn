# IM08 Vroege native Windows-proef (`burnburn-windows`) — Win32-route

Status: gedeeld deel aantoonbaar (headless, op macOS); native Win32/DX12 **onbevestigd** (geen Windows-machine).
Route: Win32 via `windows` 0.62.2 (ADR 0006 terugval/8a), WinUI niet geprobeerd.

## Opbouw
- `src/adapter.rs` (geen `windows`-dependency, getest op elk OS): Win32-berichten als getallen (`msg`, `wParam`,
  `lParam`) + `MessageContext` (document, control, DPI, edittekst, lijstselectie, Alt, cursor, tijd) → `UiIntent`.
  Decodering: signed `GET_X/Y_LPARAM`, px → punten via DPI, `WM_MOUSEWHEEL` (40 pt/notch, Ctrl = zoom rond cursor),
  `WM_MOUSEHWHEEL`, `WM_CAPTURECHANGED` → Cancel, `WM_SIZE` → viewport, `WM_COMMAND` (menu/accelerator-id,
  `EN_KILLFOCUS`, `LBN_SELCHANGE`), Enter in edit (subclass), `WM_CLOSE`, `WM_ACTIVATE`; dialoogresultaten en
  `MessageBoxW` (Ja/Nee/Annuleren). Accelerators alleen met Ctrl (Ctrl+Y en Ctrl+Shift+Z = Opnieuw).
- `src/win32/` (`cfg(windows)`): frame per document, `LISTBOX` (objecten), 4 `EDIT`-velden, statusregel, kind-`HWND`
  canvas met `render::surface::SurfaceCanvas` op DX12, `IFileOpenDialog`/`IFileSaveDialog`, per-monitor-v2 DPI, STA
  COM, taken via `PostMessageW` naar een berichtvenster. `catch_unwind` in elke window procedure.
- `src/tasks.rs`: kopie van de macOS-taakpoort (tot `burnburn-runtime` bestaat).

id's, muisdrag in fysieke px, Enter + EN_KILLFOCUS, Ctrl+S → save-dialoogresultaat) en vergelijkt met de directe
harnessroute: zelfde objecten, inspectorwaarden (150 × 80), undo-label, titel/dirty en **byte-identiek** projectbestand
(MemoryFileSystem). Enter + focusverlies = één command.
