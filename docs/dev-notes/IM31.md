## Ontwerpkeuzes
- `ActionId { kind, subject, generation }` wordt afgeleid uit de gedeelde `MachineStatus`; elk venster toont dezelfde id
  voor dezelfde knop, dus dubbelklik, tweede venster en herhaling na reconnect zijn no-ops (`Dispatched::AlreadyHandled`).
- Rol komt uit configuratie (`AppController::set_role`), nooit uit een `UiIntent`. Operator: kijken, sluiten,
  machine-acties op goedgekeurde jobs, orders; elke andere intent → `NotAllowedForRole`, alle commands disabled.
- Restmateriaal: alleen een benoemde koppeling op de order (`remnant`); geen nesting op de restplaat (IM26).
