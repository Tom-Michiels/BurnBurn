# IM14 Zuivere Rust Ruida-codec (`burnburn-ruida`)

Status: eerste deel gereed (macOS arm64). Geen sockets, klokken of bestands-IO in de crate; tests lezen fixtures
via `burnburn-test-support::fixtures::read_ruida_fixture` (hashgecontroleerd tegen `test-data/ruida/manifest.json`).

Commando's: `export PATH="$HOME/.cargo/bin:$PATH"; CARGO_TARGET_DIR=target/protocol cargo test -p burnburn-ruida [--test <bestand>]`.

## API (kort)
- `Magic` (configureerbaar; `Magic::FIXTURE_0X88` alleen bevestigd voor de drie exports), `scramble[_byte]`/`unscramble[_byte]`.
- `field`: `pack7`/`unpack7`/`unpack7_signed`; bereikgecontroleerde typen `Power` (raw14), `RelCoord` (signed14 µm),
  `AbsCoord` (35 bit unsigned µm, geen tekeninterpretatie), `Speed` (µm/s), `U35`, `Byte7`; fouten `FieldError`.
- `decode(&[u8]) -> Result<Vec<Record>, DecodeError>` op ongescrambelde bytes: begrensd (`MAX_DECODE_INPUT` = 16 MiB),
  paniekvrij, langste prefix; getypeerde subset → `Command::*`, overige registerprefixen → `Command::Registered{label, bytes}`,
  onbekend → `Command::Unknown{opcode, bytes}`. Fouten: `Truncated`, `Malformed{ShortPayload|TrailingPayload|Field}`,
  `PayloadWithoutOpcode`, `InputTooLarge`.
- `decode_rd_file(scrambled, magic) -> RdFile` controleert EOF, `E5 05`-bestandssom (`sum(raw vóór E5 05) + 0xD7`) en data na EOF.
- `encode`/`encode_command`, `encode_rd_file(body, magic)` (berekent footer, scrambelt, weigert footer in body).
- `udp::{frame, parse_frame, checksum, reply_from_wire, MAX_PAYLOAD}` (OSS-beschreven framing, pure functies).
- `registry_entries()`: 199 unieke prefixen / 200 labels uit `command-registry.json` (gegenereerd, test bewaakt drift).

## Open / onbevestigd
- Negatieve absolute coördinaten (signed32 vs signed35) — `AbsCoord` interpreteert geen teken.
- Power-procentformule (3277 bij 20 %): alleen raw14 in de API; geen `percent → raw`-conversie.
- Grayscale: `C7`/`C2`-modulatie (`ImmediatePower`) gedecodeerd als raw14; kanaal-/firmwaresemantiek OPEN.
- Delay-/kleur-/tijdschalen (`U35` raw), `CA 03`-maskerbetekenis, `C6 50/51` through-power, `DA 01 06 20`-register,
  `F2 01` (Unknown), `E7 37` e.d. (alleen label).
- Bestandssom-overflow (> 2^35 − 1) wordt bij encode geweigerd; gedrag van firmware/LightBurn niet gemeten.
- UDP-framing en ACK/NAK/ERR/ENQ-waarden zijn OSS-beschreven, niet via capture bevestigd. Geen live IO in deze crate.
- Fuzz-target (`cargo-fuzz`) voor `decode` is fuzz-klaar maar nog niet aangemaakt (eigendom Testing: `fuzz/`).
- Firmware-/modelvarianten en magic per controller: onbevestigd.
