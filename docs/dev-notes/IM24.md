# IM24 Geavanceerde tracerecepten

Status: groen op macOS arm64, headless; holdout-benchmark wacht op de split van Testing. Windows: onbevestigd.
Rol: Implementatie (beeld/trace). Crates: `burnburn-image` (drempel, perspectief), `burnburn-trace` (`recipes`).

## Opgeleverd
- **Lokale belichting:** `Threshold::Adaptive { radius, offset }` — voorgrond als een pixel meer dan `offset`
  grijswaarden donkerder is dan het gemiddelde van het `(2r+1)²`-venster (randen geknipt, integraalbeeld);
  `radius` 1…`MAX_ADAPTIVE_RADIUS` (256), anders `RadiusTooLarge`. Globaal (Fixed/Otsu) blijft apart kiesbaar (T03).
- **Perspectief:** `ImageRecipe.perspective: Option<Perspective { points: Vec<(foto, rechtgezet)>, width, height }>`;
  `Homography::from_points` (DLT met Hartley-normalisatie, kleinste kwadraten bij > 4 paren) →
  `PreparedImage.perspective = Some(PerspectiveReport { homography, residual_px })` (de vlaktransformatie die de UI
  toont). Bilineair warpen ná uitsnede/rotatie; `scale` geldt dan voor rechtgezette pixels. Collineair/te weinig
  punten/nulgrootte → `ImageError::DegeneratePerspective`. Alleen vlakke objecten (geen lens/kromming).
  Receptsleutels zonder perspectief zijn ongewijzigd (veld wordt alleen gecodeerd als het bestaat).
- **A/B:** `compare_recipes(source, a, b, task, cancel)` → twee `RecipeSummary` (recipe_key, `geometry_hash`, paden,
  vormen, gaten, knopen, verwijderd, max afwijking) + beide resultaten in hetzelfde frame.
  `TraceResult::geometry_hash()`: id, soort en pad van elke contour + engine (T10: zelfde bron/recept/engine ⇒ zelfde hash).
- **Batch:** `trace_batch(items, recipe, task, revision, cancel)` → `BatchReport` per beeld (`NoGeometry`,
  `RemovedFeatures { count }`, `Failed(TraceError)`); een fout beeld stopt de batch niet, annuleren wel (geen half rapport).
- **Correctie opnieuw toepassen:** `reapply_correction(record, new_base, source, task, cancel)` →
  `Reapplied::Applied` alleen als de basis exact dezelfde is (`base_inputs`) óf elke binding (id + soort + oppervlak
  ±10 % + bounds-IoU ≥ 0,8) nog klopt en de regio geen onbekende contour bevat; anders
  `NeedsRebind { lost, new_in_region }` en er wordt niets toegepast (T05 "meldt correcties waarvan de bronkoppeling
  verloren is").

## Holdout

holdout-cases die niet voor de defaults gebruikt zijn. Tot dan zijn álle 8 huidige cases *tuning* (ik heb er
centerline-toleranties op gekozen). Benchmark: `cargo test -p burnburn-trace --release --test holdout -- --ignored --nocapture`.
