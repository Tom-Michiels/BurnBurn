# IM28 Migratie (LBRN2), profielsnapshots, revisies en projectzoeken

Status: gereed op macOS arm64, headless. Rol: Kern. PDF: **bewust niet geïmplementeerd** (`NotSupportedYet`).
Commando's: `export PATH="$HOME/.cargo/bin:$PATH"; CARGO_TARGET_DIR=target/core cargo test -p burnburn-io --test <bestand>`.

## Opgeleverd
- `burnburn_io::import::lbrn2`: `parse_lbrn2(_with)` (fuzz-entry), `SUPPORTED` + `supported_attributes(element)` =
  de **gepubliceerde subset**: root (`AppVersion`, `FormatVersion`), `CutSetting`/`CutSetting_Img` met `index, name,
  minPower, maxPower, speed, numPasses, interval`, shapes `Rect` (incl. `Cr`), `Ellipse`, `Path` (`VertList`/`PrimList`:
  lijnen, `B`-Béziers, `LineClosed/LineOpen`, gedeelde lijsten via `VertID`/`PrimID`), `Group`/`Children`, `XForm`.
  `Text` → `FontUse` (familie, aantal, met outlines), outlines alleen uit een aanwezige `BackupPath`; `Bitmap` →
  `AssetNote` (gelinkt bestand, ingebedde lengte). Alles anders → `ImportNote { kind: UnknownElement | UnknownAttribute
  | UnmappedSetting | UnsupportedShape | NotConverted | InvalidValue, name, count }`.
- Cut settings → `CutSettingProposal { kind, draft: Option<OperationDraft>, assumptions, items }`, **output uit**;
  aannames (mm/s, minPower = maxPower, 1 pass, interval 0,1 mm, scan X bidirectioneel, air uit) zichtbaar.
  Commit via `Lbrn2Draft::geometry_command(asset)` + `operation_commands(&created)` → CAM's `ProcessCommand::AddOperation`.
- `ImportFormat::{Svg, Dxf, Lbrn2, Png, Jpeg, Pdf}`, `from_extension`, `check_supported`, `analyze(format, bytes)` →
  `Analysis`; **PDF → `ImportError::NotSupportedYet(Pdf)`** (lopdf = open eigenaarsbeslissing van Design).
- XML-tokenizer: `Tokenizer::with_text` (tekstinhoud voor XForm/VertList); SVG ongewijzigd.
- Profielsnapshots: `Project.profiles: Vec<MachineProfile>` in `profiles.json` (alleen indien aanwezig), contenthash
  bij laden herberekend en vergeleken; `compare_profile(frozen, local)` → `Identical | Differs { fields } |
  OtherMachine` — nooit automatisch toegepast. io → `burnburn-job` (toegestaan in layers.toml).
- Herhaalrevisies: `Project::freeze_revision(label)`, `revision(n)`, `recreate_revision_project(n)` ("opnieuw maken als
  revisie X"); `revisions.json` met volledige documenten + projecthash, bij laden geverifieerd.
- Projectzoeken: `burnburn_io::search::{index_projects(fs, dir), ProjectIndex::search(q)}` over bestandsnaam,
  objecten, operations, materialen (recepten + platen), parts, platen, revisielabels; onleesbare projecten in `issues`.
- `FileSystem::{append, list_dir}` (C-7/DR-24) met default-implementaties (andere implementaties blijven compileren);
  echt in `StdFileSystem`/`MemoryFileSystem` (+ `tear_next_append(k)`).

## Onbevestigd / open
- LBRN2-semantiek tegen LightBurn zelf: assenrichting (y-up aangenomen), `c0x1`-markering = "geen controlepunt",
  `B a b` = c0 van a en c1 van b, Rect/Ellipse gecentreerd op de oorsprong vóór `XForm`, snelheid in mm/s. Alleen de
  drie eigen fixtures (publieke XML van onze tekening) zijn gebruikt; geen ander corpus.
- Bitmaps worden niet geïmporteerd (alleen gerapporteerd); tekst zonder `BackupPath` wordt niet gezet (FontUse-melding).
- Import + proposals zijn 1 + N undo-stappen (geen samengestelde command).
- Zoekresultaten: geen preview/revisiedatum (geen klok in io; de host kan bestandstijden tonen). Index in io i.p.v.
  `burnburn-history` (contract): de opdracht vroeg de `FileSystem`-poort; history kan hem hergebruiken.
- Werkplaatspakket `.burnburnpack` en ingebedde fonts: niet in deze ronde.

## W2-L6 — PDF/AI-import (lane L6, 20-10-2026)

**Beslissing (de open `lopdf`-vraag):** een **eigen, begrensde lezer**, geen `lopdf`. Redenen: (1) `lopdf` 0.45 trekt
`aes`/`cbc`/`ecb`/`md-5`/`rand`/`nom`/`encoding_rs` mee voor functies die we niet gebruiken (versleuteling weigeren we
toch); (2) de benodigde subset is klein (xref + objectstreams, Flate, padoperatoren) en met een eigen lezer zijn de
limieten toetsbaar (decode-cap per stream en totaal, operator-/segment-/nestingplafond) — dezelfde afweging als IM10 voor
SVG; (3) geen wijziging van het dependencyregister. Flate (RFC 1950/1951) is **eigen code** (`import/pdf/inflate.rs`,
canonical-Huffman) zodat ook `flate2` niet direct nodig is; het onafhankelijke oracle in de tests is de deflate-encoder
van het `zip`-dev-dependency. `roxmltree` blijft ongebruikt (eigen XML-tokenizer). **Nieuwe dependencies: geen.**

Module `burnburn_io::import::pdf` (`parse_pdf(_with)`, `parse_ai_with`, `PdfDocument::{pages, to_draft(PdfPages), import_command}`),
`ImportFormat::{Pdf, Ai}`, `Analysis::Pdf`, `UnitDecision::Pdf`. Twee stappen zoals DXF: eerst de pagina-keuze, dan de draft.
**Meerdere pagina's:** `PdfPages::One(i)` of `All` (naast elkaar, 10 mm tussenruimte); de UI laat de gebruiker kiezen
(wachtrij). Eenheden: 1 pt = 25,4/72 mm × `UserUnit`; paginakader = `CropBox` binnen `MediaBox`, `Rotate` t/m 270°;
linksonder = wereld-oorsprong (y omhoog), dus gelijk aan de SVG-import.
Ondersteund: `q Q cm m l c v y h re`, `S s f F f* B B* b b* n`, kleurnaam (`G g RG rg K k` → itemnaam `stroke #rrggbb` /
`fill #rrggbb`, voor laagtoewijzing door de UI), form-XObjects (Matrix, recursie-/dieptebewaking), optionele inhoud
(OCG's die in `/D /OFF` staan of `BaseState /OFF`, ook OCMD) wordt overgeslagen en gemeld (`optional content`),
xref-tabellen én -streams (+ `/Prev`, hybride `/XRefStm`), objectstreams, Flate met PNG-/TIFF-predictor, ASCIIHex,
ASCII85, voorloopbytes vóór `%PDF-` (offsets relatief aan de header), herstel door scannen bij een beschadigde xref.
Gemeld, niet stil weggelaten: tekst (`BT`), beelden (`Do`/`BI`), shadings (`sh`), clippaden (`W`, niet toegepast), andere
XObjects, onbekende operatoren, onbruikbare contentstreams (te groot/beschadigd/filter niet ondersteund). Geweigerd met
getypeerde fout: versleuteld (`Unsupported("encrypted PDF")`), geen PDF, legacy PostScript-`.ai`
(`%!PS-Adobe`) met de tekst "save it with PDF compatibility or export SVG".
