# IM25 Uitgebreide laserprocessen (rol CAM/job)

Status: eerste deel gereed op macOS arm64. Geen hardware; elke "Supported" in de standaardmatrix betekent alleen
"uitgedrukt met dezelfde planevents als Line/Fill", **niet** "op een machine bewezen".

## Opgeleverd
- `burnburn-job::{Feature, Support::{Supported, Unsupported, Unverified{reason}}, MachineCapabilities}`;
  `MachineProfile::with_capabilities` (matrix is profielinhoud, DR-18). Standaard (`conservative`): Supported = kerf,
  OffsetFill, ImageDither, Tabs, Leads, Overcut, Perforation, SubOperations; **Unverified** = ScanAngle,
  GrayscaleModulation, CommonLine; **Unsupported** = ZStep.
- `PlanMode::{AngledScan, GrayscaleScan}`, `PlanEvent::{PowerRun, FocusOffset}` (builder valideert modus/hoek).
- `document::process`: `OperationMode::OffsetFill(OffsetFillSettings{step, order})`, `FillSettings::with_angle`,
  `AdvancedOptions { line: LineOptions{tabs, lead_in, lead_out, overcut, perforation}, z_step, sub_operations,
  shared_edges }` via `ProcessCommand::SetAdvanced` (één transactie, label `SetAdvanced`). Canoniek: zonder nieuwe
  opties exact de IM13-layout (bestaande hashes blijven geldig); gedraaide fill krijgt tag `fill-angled`.
- `cam`: `required_features(op)`, compile weigert elke niet-`Supported` feature met
  `CompileError::UnsupportedFeature{operation, feature, support}` (nooit vervangen); `LineOptionsOnNonLineMode`,
  `InvalidTabs`. Preflight: `Finding::UnsupportedFeature` (bv. na machinewissel). Lower weigert `GrayscaleScan`
  ("grayscale modulation"), `AngledScan` ("scan angle"), `FocusOffset` ("focus offset").
- io: save weigert advanced opties, scanhoek en nieuwe modi (schema 2 heeft er geen velden voor) i.p.v. ze te laten vallen.

## Open / onbevestigd
- Featurematrix tegen de LightBurn-matrix (C11: benoemde status, uitvoerbetekenis en fixture per optie): nog niet
  afgestemd; geen fixtures voor tabs/leads/overcut/perforatie. Puntmarkering, kanaal-/delay-opties: niet gebouwd.
- Z-step: geen backend; alleen planevent. Scanhoek: geen RD. Common-line cutting (C12): alleen featurevlag.
- "Ongeldige tabplaatsing na bronwijziging" = compile-fout `InvalidTabs`; nog geen preflight-melding vóór compile.
- Leads op open paden verlengen de raaklijn; botsing van leads met andere delen wordt niet gecontroleerd.
- io-schema voor de nieuwe opties: verzoek aan Kern (`cam.md`).

# W1-L3 Line- en Fill-extra's (lane L3, golf 1)

Status: domein, compiler, preflight en bestandsvorm gereed op macOS arm64; geen hardware. "Supported" betekent ook
hier alleen "uitgedrukt met dezelfde planevents als Line/Fill", niet "op een machine bewezen". Zie
`docs/plan/integratie-wachtrij.md` voor de UI-velden (L1).

## Opgeleverd

- `burnburn-job`: `PlanMode::Dots{dwell_ms}`, `PlanEvent::{Dot, RampRun}`, `MoveKind::Dot`; builder valideert
  modus/dwell/ramp; `Feature::{DotMode, CrossHatch, FloodFill, FillGrouping, RampLength}`. Standaardmatrix:
  CrossHatch/FloodFill/FillGrouping **Supported** (gewone scanevents, andere volgorde/herhaling),
  DotMode/RampLength **Unverified** (geen RD-vorm). Profielhash blijft voor ongewijzigde profielen gelijk: de
  eerste 12 features staan altijd in de hash, latere alleen als hun steun van de default afwijkt.
- `burnburn-document::process`: `TabSpec::spaced` + `TabPlacement`, `Lead::{with_style(Line|Arc), with_angle}`,
  `DotMode`, `LineOptions.dot`, `FillSettings::{with_cross_hatch, with_flood_fill, with_grouping(FillGrouping),
  with_ramp}`; `ProcessError::ConflictingOptions` (dot sluit tabs/leads/overcut/perforatie uit). Canoniek:
  zonder nieuwe opties exact de oude layout (blok `advanced-ext` en tag `fill-ext` bestaan alleen als er iets
  nieuws gezet is).
- `burnburn-cam`: tabs op afstand (n = round(omtrek / afstand), min 1, max 64; anders `InvalidTabs`), lead-hoek en
  boog-leads (kwartcirkel binnen de productietolerantie; boog op open pad = `ArcLeadOnOpenContour`), overcut alleen op
  de laatste pass, dot-modus (`TooManyDots` als begrenzing), cross-hatch (tweede settingsblok loodrecht, zelfde pass),
  flood fill (verbonden gebieden volledig, dichtstbijzijnde eerst), fill grouping (alles/rootgroepen/per geometrie),
  ramp (`RampRun`). Preflight: `Finding::InvalidTabs` (C04) uit de bron, vóór compile.
- `burnburn-macos/src/l10n.rs` (L1-bestand, 5 regels in `feature_pair`): NL/EN-namen voor de nieuwe features. Eerste
  `cargo xtask verify` faalde op `macos::l10n::all_message_keys_have_nl_and_en` (`missing translations: MissingCapability(DotMode) …`)
  omdat de teksttabel over `Feature::ALL` loopt; na de 5 regels groen (verify: 952 passed, 0 failed).
- `burnburn-io`: schema 2 additief — `tabs.spacing_mm` (i.p.v. `count`), `lead_*_style`/`lead_*_angle_deg`, `dot`,
  fill `cross_hatch`/`grouping`/`flood_fill`/`ramp_mm`; allemaal weggelaten bij default, dus oude bestanden en hashes
  blijven gelijk. Formaat is additief, geen schema-bump (oude lezers met `deny_unknown_fields` weigeren nieuwe bestanden).

## Open / onbevestigd

- **RD**: Ruida-lowering (L4) lokt geen Y-as-scan (cross-hatch), `Dots`-modus of `RampRun`; ze falen getypeerd
  (`scenarios::process_extras_rd::extras_without_a_proven_rd_form_are_typed_lowering_errors`). Wijzigt L4 dat, dan
  moet die test bewust worden bijgewerkt. `history::plan_blob` kan Dots/RampRun/Y-scans evenmin opslaan (`PlanBlob`-fout).
- Tab-/ramp-**snijvermogen** (Tab Cut Power), start/end pause, PWM-frequentie, U-offset, Z-per-pass-UI: niet in deze golf.
- `Finding::InvalidTabs` gebruikt de nominale omtrek (vlak op 0,01 mm, zonder kerf); compile blijft de autoriteit.
- Ramp is hier gedefinieerd als lineaire stijging min→max over de eerste/laatste `ramp_mm` van elke run (max. halve
  run); "Ramp Outer Edge" (alleen buitenranden) is niet gemodelleerd. LightBurn-gedrag niet aan de hand van een
  LightBurn-fixture vergeleken — semantiek is eigen ontwerp, Unverified.
- Fill-grouping "rootgroepen" gebruikt de buitenste groep van een geometrie; "per vorm" = per doelgeometrie (een pad met
  eilanden telt als één vorm). Flood fill verandert alleen de volgorde, niet de gescande oppervlakte.
- `docs/user-flows/story-coverage.md` (C04 → `tab_invalid_after_source_change_is_reported` ✔) is van L7.
