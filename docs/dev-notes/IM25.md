# IM25 Uitgebreide laserprocessen (rol CAM/job)

Status: eerste deel gereed op macOS arm64. Geen hardware; elke "Supported" in de standaardmatrix betekent alleen
"uitgedrukt met dezelfde planevents als Line/Fill", **niet** "op een machine bewezen".

## Opgeleverd
- `burnburn-job::{Feature, Support::{Supported, Unsupported, Unverified{reason}}, MachineCapabilities}`;
  `MachineProfile::with_capabilities` (matrix is profielinhoud, DR-18). Standaard (`conservative`): Supported = kerf,
  OffsetFill, ImageDither, Tabs, Leads, Overcut, Perforation, SubOperations; **Unverified** = ScanAngle,
  GrayscaleModulation, CommonLine; **Unsupported** = ZStep.
- `PlanMode::{AngledScan, GrayscaleScan}`, `PlanEvent::{PowerRun, FocusOffset}` (builder valideert modus/hoek).
- `document::process`: `OperationMode::OffsetFill(OffsetFillSettings{step, order})`, `FillSettings::with_angle`,
  `AdvancedOptions { line: LineOptions{tabs, lead_in, lead_out, overcut, perforation}, z_step, sub_operations,
  shared_edges }` via `ProcessCommand::SetAdvanced` (één transactie, label `SetAdvanced`). Canoniek: zonder nieuwe
  opties exact de IM13-layout (bestaande hashes blijven geldig); gedraaide fill krijgt tag `fill-angled`.
- `cam`: `required_features(op)`, compile weigert elke niet-`Supported` feature met
  `CompileError::UnsupportedFeature{operation, feature, support}` (nooit vervangen); `LineOptionsOnNonLineMode`,
  `InvalidTabs`. Preflight: `Finding::UnsupportedFeature` (bv. na machinewissel). Lower weigert `GrayscaleScan`
  ("grayscale modulation"), `AngledScan` ("scan angle"), `FocusOffset` ("focus offset").
- io: save weigert advanced opties, scanhoek en nieuwe modi (schema 2 heeft er geen velden voor) i.p.v. ze te laten vallen.

## Open / onbevestigd
- Featurematrix tegen de LightBurn-matrix (C11: benoemde status, uitvoerbetekenis en fixture per optie): nog niet
  afgestemd; geen fixtures voor tabs/leads/overcut/perforatie. Puntmarkering, kanaal-/delay-opties: niet gebouwd.
- Z-step: geen backend; alleen planevent. Scanhoek: geen RD. Common-line cutting (C12): alleen featurevlag.
- "Ongeldige tabplaatsing na bronwijziging" = compile-fout `InvalidTabs`; nog geen preflight-melding vóór compile.
- Leads op open paden verlengen de raaklijn; botsing van leads met andere delen wordt niet gecontroleerd.
- io-schema voor de nieuwe opties: verzoek aan Kern (`cam.md`).
