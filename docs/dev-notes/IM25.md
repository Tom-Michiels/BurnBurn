# IM25 Uitgebreide laserprocessen (rol CAM/job)

Status: eerste deel gereed op macOS arm64. Geen hardware; elke "Supported" in de standaardmatrix betekent alleen
"uitgedrukt met dezelfde planevents als Line/Fill", **niet** "op een machine bewezen".

## Opgeleverd
- `burnburn-job::{Feature, Support::{Supported, Unsupported, Unverified{reason}}, MachineCapabilities}`;
  `MachineProfile::with_capabilities` (matrix is profielinhoud, DR-18). Standaard (`conservative`): Supported = kerf,
  OffsetFill, ImageDither, Tabs, Leads, Overcut, Perforation, SubOperations; **Unverified** = ScanAngle,
  GrayscaleModulation, CommonLine; **Unsupported** = ZStep.
- `PlanMode::{AngledScan, GrayscaleScan}`, `PlanEvent::{PowerRun, FocusOffset}` (builder valideert modus/hoek).
- `document::process`: `OperationMode::OffsetFill(OffsetFillSettings{step, order})`, `FillSettings::with_angle`,
  `AdvancedOptions { line: LineOptions{tabs, lead_in, lead_out, overcut, perforation}, z_step, sub_operations,
  shared_edges }` via `ProcessCommand::SetAdvanced` (één transactie, label `SetAdvanced`). Canoniek: zonder nieuwe
  opties exact de IM13-layout (bestaande hashes blijven geldig); gedraaide fill krijgt tag `fill-angled`.
- `cam`: `required_features(op)`, compile weigert elke niet-`Supported` feature met
  `CompileError::UnsupportedFeature{operation, feature, support}` (nooit vervangen); `LineOptionsOnNonLineMode`,
  `InvalidTabs`. Preflight: `Finding::UnsupportedFeature` (bv. na machinewissel). Lower weigert `GrayscaleScan`
  ("grayscale modulation"), `AngledScan` ("scan angle"), `FocusOffset` ("focus offset").
- io: save weigert advanced opties, scanhoek en nieuwe modi (schema 2 heeft er geen velden voor) i.p.v. ze te laten vallen.

# W2-L3 Optimalisatie, testgeneratoren, rotary en RD-lowering (lane L3, golf 2)

Status: domein, compiler, io-schema (additief) en RD-lowering gereed op macOS arm64; geen hardware, UI via
`docs/plan/integratie-wachtrij.md`. Bewijsstand per feature: `docs/hardware/evidence-cam.md`.

## Opgeleverd

- `document::process::{OptimizationSettings, OrderKey::{Layer, Group, Priority}, CutPriority}` op de `ProcessLayer`
  (`ProcessCommand::{SetOptimization, SetPriority}`, undo-labels `SetOptimization`/`SetPriority`). Default = de planner van
  vóór deze wijziging: hiërarchie `[Layer]`, inner-first, nearest neighbour, beste start, beste richting, geen
  overlapverwijdering, geen backlash-heuristiek. Canoniek schrijft de proceslaag het blok `optimization` alleen als
  instellingen of prioriteiten afwijken; projecten zonder behouden hun hash en bestandsvorm.
- `cam`: de compiler ordent **chunks** (een eenheid = operation of sub-operation, gesplitst op de Group-/Priority-niveaus uit de
  hiërarchie) op de hiërarchie als sorteersleutel (meest significant eerst); niet-genoemde niveaus splitsen of herordenen
  niets en breken alleen gelijkspel (Layer laatst). Binnen een chunk: inner-first als containment-DAG, daarna deterministische
  nearest-neighbour met bekende tie-break (invoervolgorde). `Heuristics{inner_first, reduce_travel, best_start,
  best_direction, hide_backlash}`; Remove Overlapping Lines (`overlap.rs`) werkt op de geplande stappen van één laag en pass
  met afstandstolerantie (convexe-interval-zoeker, gridindex), vergelijkt alleen met andere vormen, onthoudt alleen behouden
  stukken en laat de brongeometrie ongemoeid. `hide_backlash`: eigen heuristiek, aanrijkosten + `BACKLASH_REVERSAL_PENALTY_MM`
  (1 mm) als de kop bij het begin van de snede van richting omkeert.
- Focusbewaking in de compiler: een operation zonder focuswijziging na een met focus zet de focus terug naar 0 (voorheen bleef
  de laatste `FocusOffset` doorlopen). `AdvancedOptions::z_offset` (`ZOffset`, 0 < |z| ≤ 50 mm, `Feature::ZStep`).
- `cam::test_job::{generate_material_test, generate_interval_test, generate_focus_test}`: een eigen document per test
  (`TestJob::snapshot()`), compilatie via dezelfde `compile`; cellen per twee parameters (Speed, Power, Passes, Interval,
  ZOffset), min/max/count (≤ 25 per as, ≤ 100 cellen = RD-parts), vakmaten, labels (eigen zevensegment-streeplettertype, geen
  fontbestanden) en rand. Focus Test weigert vooraf zonder `ZStep: Supported`.
- `job::{RotaryConfig, RotaryKind::{Chuck, Roller}}`, `MachineProfile::{with_rotary, without_rotary, rotary, flatbed_frame}`,
  `JobPlan::rotary()`. Het plan blijft in oppervlakte-mm; `ruida::lower` schaalt Y vlak voor het kwantiseren
  (`schaal = steps_per_rotation / (π·D · y_steps_per_mm)`, spiegelen = `H − y`). Bevroren profielen (io) bewaren de rotary en de
  vlakbed-hoogte; `compare_profile` noemt `rotary`.
- RD-lowering: cross-hatch (`scan axis Y`), dot mode (`dot mode`) en ramp length (`ramp length`) blijven getypeerd geweigerd met
  eigen reden; er is geen fixture of waarneming (`evidence-cam.md`).
- io schema 2 additief: `optimization`, `priorities`, `advanced.z_offset_mm`, profiel-`rotary`.

## Open / onbevestigd

- `Layer` weglaten uit de hiërarchie mengt geen reis tussen lagen (LightBurn doet dat wel): chunks van verschillende eenheden

## Ontwerp
- Nieuwe presentation-module `cut_options.rs`: `CutField` (39 velden), `CutValue` (`Text`/`Flag`/`Choice`), `CutExtras` (veld → waarde; afwezig = ongewijzigd),
  `CutGates` (per veld/keuze de reden uit `MachineCapabilities`), `FieldState` (Hidden/Editable/Disabled(reden)). `CutSettingsInput.extras` en
  `CutSettingsViewModel.{extras, gates}` zijn additief; `OperationKind::Image`, `MessageKey::{InvalidCutField, CutOptionsConflict, CutOptionNotForMode}`.
- Logica in `controller/cut_options.rs` (nieuw) en `controller/layers.rs`: een veld wordt alleen toegepast als de tekst **verschilt van wat de sheet toonde**
  (dus "gelijke waarde = geen command" en geen afronding via de 3-decimalen weergavetekst). Features die de operatie na de wijziging méér nodig heeft dan
  ervoor (`burnburn_cam::required_features`-verschil) moeten `Supported` zijn, anders `MissingCapability` en geen command; bestaande opties blijven staan
  en blokkeren andere wijzigingen niet.
- Commands: modus/instellingen = één `UpdateOperation`, lijnopties = één `SetAdvanced`. **Beperking**: het document heeft geen gecombineerd command,
  dus een OK die beide raakt is twee undo-stappen (getest als karakterisering). Volgorde: weggaan uit Line wist de lijnopties eerst (anders
  `CompileError::LineOptionsOnNonLineMode` tussenin), erheen zet eerst de modus.
- Image-bewerking: een beeldlaag houdt `Image` (modus-wissel = `CommandRejected`); de sheet herbouwt `ImageSettings` uit de opgeslagen waarden + gewijzigde velden,
  zodat tone/sharpen/crop/mask (W2-L1-beeld) onaangeroerd blijven. Pass-through/Grayscale met hoek ≠ 0 → `CutOptionNotForMode(ImageAngle)` (cam weigert dat ook).
- Interval/puntafstand van beelden accepteren `0,1 mm` of `254 dpi`.
