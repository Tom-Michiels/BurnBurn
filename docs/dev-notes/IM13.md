# IM13 Operations en compiler (proceslaag, `burnburn-job`, `burnburn-cam`)

Status: eerste deel gereed op macOS arm64 (rol CAM/job). Kerfcompensatie: **niet ondersteund** (getypeerde fout).

Commando's: `export PATH="$HOME/.cargo/bin:$PATH"; CARGO_TARGET_DIR=target/cam cargo test -p <crate> [--test <bestand>]`.

## Opgeleverd
- `burnburn-document::process` (nieuw, eigendom CAM): `Operation` (naam, `OperationMode::{Line{kerf}, Fill(FillSettings)}`,
  `ProcessSettings { speed mm/s, PowerRange %, Passes, air }`, geordende targets zonder duplicaten, output-flag,
  `RecipeRef`), `ProcessLayer` (lijstvolgorde + `OrderConstraint`s + `MaterialRecipe`-bibliotheek), stabiele
  topologische `execution_order()` met cyclusfout die de betrokken operations noemt, canonieke projectie.
  `ProcessCommand` via `CommandPayload::Process` (één transactie, undo/redo, revisie). `Delete` verwijdert targets in
  dezelfde transactie. Gedeelde edits in `command.rs`/`snapshot.rs`/`session.rs`/`lib.rs`: zie `docs/coordination/cam.md`.
- `burnburn-job` (nieuw, laag 2): `JobPlan` (privévelden, `JobPlanId` = `ContentHash::of(Plan, canoniek)` zonder
  sessierevisie), `JobPlanBuilder` (valideert events tegen hun settings), `PlanEvent::{OperationBoundary{pass}, Travel,
  Cut, ScanRun}`, `MachinePoint`, `PowerRatio`, `PlanUnits::MillimetreSecond`, `MachineFrame` (bed + oorsprongshoek,
  exacte `contains`), `MachineProfile` met `ProfileRevision { id, revision, content }` (DR-18).
- `burnburn-cam` (nieuw, laag 3): `compile(&DocumentSnapshot, &MachineProfile, &CompileOptions, &CancellationToken)`:
  `ProductionTolerance`-flattening, plaatsing (absoluut / 9-punts anker), oorsprong via frame, line-planning (binnen vóór
  buiten via containment, daarna dichtstbijzijnde ingang; gelijke afstand → targetvolgorde), fill (rijcentra, even-odd,
  half-open kruisregel, bi/unidirectioneel, X/Y, overscan op elke run), passes, annulering, `source_hash`.
- `burnburn-io` schema **2**: operations met `targets: [{ "geometry": id }]` (DR-15) en `process`-blok, optioneel
  `constraints`/`recipes`. Schema 1 laadt nog; placeholder-operations migreren naar **uitgeschakelde** Line-operations
  met inerte instellingen (`MIGRATED_V1_SPEED_MM_S` = 10, `MIGRATED_V1_POWER_PCT` = 0). `Project.operations` en
  `OperationPlaceholder` zijn vervallen (operations wonen in de snapshot). Projecthash ongewijzigd voor projecten zonder
  operations (handgecodeerde test groen).

- Fill: even-odd over alle contouren van één operation (overlappende objecten vullen als xor); niet tegen LightBurn
  gemeten. Niet-integrale hoogte/interval: rijblok gecentreerd (afrondingsgedrag LightBurn niet gemeten).
- Startpuntbeleid: dichtstbijzijnde hoek/vertex vanaf de kop; LightBurn kiest in de fixtures anders (zie IM15.md).
- DR-13 (libm): flattening van bogen gebruikt OS-`acos`/`sin_cos` via geometry → plan-id kan per platform 1 ulp
  verschillen tot Kern DR-13 afrondt. Alleen macOS arm64 getest.
