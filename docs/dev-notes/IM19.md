# IM19 Lokale tracecorrectie

Status: groen op macOS arm64, headless. Windows: onbevestigd (geen runner).
Rol: Implementatie (beeld/trace). Crate: `burnburn-trace` (module `correct`), kleine uitbreiding `burnburn-image`.

## Opgeleverd
- `ContourId` (stabiel binnen een tracelijn) + `ContourOrigin::{Trace, Correction(CorrectionId)}` op elke
  `TracedContour`; `TraceResult` draagt nu `recipe`, `base_key`, `corrections`, `next_contour_id` en (crate-intern)
  het getraceerde subpixelveld.
- `retrace_region(&CorrectionRequest, &CancellationToken)`: regio (`RegionShape`, aangepaste pixels), lokaal recept
  (zelfde schaal/uitsnede/rotatie/diagonaalbeleid, anders `CorrectionMismatch`), `anchors` (exacte knoop),
  `protected` (`BTreeSet<ContourId>`; contour + alles wat hij omsluit blijft het oude veld; verandert hij toch →
  `ProtectedChanged`, onbekend → `UnknownContour`), optioneel `NodeTarget { max_nodes, max_tolerance_mm }`.
- Werkwijze: veld = oud veld buiten regio/beschermd gebied, lokaal veld erbinnen → contouren opnieuw extraheren →
  matchen op exact gelijke subpixelpunten. Ongewijzigde contour: verbatim overgenomen (id, oorsprong, pad).
  Deels gewijzigde contour: houdt id en elk segment waarvan de brondata ongewijzigd is; alleen de tussenstukken
  worden opnieuw gefit met de eindknopen van de behouden segmenten als vaste ankers (`fit_open_indexed`).
  Nieuwe contour: nieuw id ≥ `next_contour_id` (nooit hergebruik).
- `CorrectionRecord` (bronidentiteit): id, regio, lokaal recept + `local_key`, `base_inputs`, ankers, beschermd,
  knoopdoel + `NodeTargetOutcome { met, nodes, tolerance_mm }`, `touched`/`untouched_in_region` (`ContourBinding`:
  id, soort, oppervlak, bounds), `created`, `removed`. `recipe_key` van een gecorrigeerd resultaat =
  `correction_chain_key(base_key, &corrections)`; `check_fresh` werkt daardoor ongewijzigd (DR-14).
- `deviation_map(&TraceResult)` → `DeviationMap` (raster max-afwijking mm per pixelcel, per-segmentlijst met
  `contour_id`, slechtste segment). `SegmentDeviation` kreeg `contour_id`.
- `burnburn-image`: `RegionShape::contains_pixel` en `RegionShape::validate` publiek (waren crate-intern).

## Numerieke afspraken
- Beschermd gebied: pixels binnen ±2,5 px (Chebyshev, pixelcentrum) van een bronpunt of binnen de contour
  (even-odd); daar blijft het oude veld, dus marching squares geeft exact dezelfde punten.
- Anker telt als het binnen 1 px (gem. mm/px) van de nieuwe omtrek ligt; de knoop komt exact op het anker.
- Knoopdoel: tolerantie verdubbelt vanaf `recipe.fit.tolerance_mm` tot hoogstens `max_tolerance_mm`; alleen
  opnieuw gefitte delen en nieuwe contouren veranderen. Niet gehaald → `met = false`, nooit verborgen.
