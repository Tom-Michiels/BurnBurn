## DR-afhandeling
- **DR-02** `burnburn_editor::view::{Camera, Viewport}` is de enige camera: `world_to_px`, `size_px`, `pan_by_points`,
  `zoom_at` met de semantiek van `burnburn-render/src/camera.rs` (centrum in afgeronde device-pixels, ook voor
  `points_to_world`). `burnburn_editor::scene::{SceneSnapshot, SceneItem, StyleRole, Overlay, build_scene}` (contract
  §5) + `AppController::scene(document)`. GUI zet `render` om (afspraak in `docs/coordination/userflow.md`/`gui.md`).
- **DR-03** Code gebruikte al `DocumentId`/`RevisionId`/`GeometryId`; `presentation-api.md` bijgewerkt.
- **DR-04** `UiIntent::Pointer { document, event: ViewPointerEvent }` in logische canvaspunten; presentation rekent
  met de venstercamera om naar `editor::PointerEvent { position: Point }` (mm). Tools krijgen `mm_per_point` voor
  schermtoleranties. Camera-invoer is `UiIntent::Camera(CameraIntent::{Scroll, Magnify, Resized})`.
- **DR-05** `parse_length`/`parse_position` in presentation zijn de enige parsers (ook voor getypte tekenmaten).
- Contract §4 "editor kent geen RequestId/RevisionId": `ToolStep::Commit(EditCommit)`; `presentation::commit`
  maakt er precies één `DocumentCommand` van. `ToolState::{Committing, Cancelled}` vervallen.
