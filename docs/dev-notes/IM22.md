# IM22 Lasergenerators en personalisatie — Generators/tekst

Status: generatorfuncties groen op macOS arm64, headless. Windows: **onbevestigd**. Documentintegratie
(`document::generator` + `DerivedOwner::Generator`, C-2) **nog niet**: generators leveren `GeneratedPart`s met
stabiele keys en `to_outputs(owner, parts)` → `Vec<DerivedOutput>` voor een `DocumentPatch`.

## Opgeleverd (`burnburn-generators`, L4)
- `FingerJoint::profile` (oneven aantal ≥ 3, gelijke segmenten, `fit` = ontwerpspeling, **geen kerf**),
  `tab_and_slot`, `finger_box` (gesloten/open, buitenmaten, complementaire randen), `living_hinge` (verspringende
  kolommen met exacte bruggen), `stencil_bridges` (verticale brug per gat, boolean via `geometry::boolean`,
  annuleerbaar), `text_on_path` (baseline-midden op booglengte, rotatie naar koorde, offset langs linkernormaal,
  `reverse`), `DataTable::parse_csv` (RFC 4180-achtig, begrensd), `FrozenRows::freeze` (hash over rijen +
  geïnjecteerde tijdwaarde), `resolve`/`resolve_bound` (`{kolom}`, `{#}`, `{datum}`, escapes, ontbrekende velden,
  `StaleRows`), Code 128 B/C (`code128_symbols`, `code128`, minimale modulegrootte, quiet zone ≥ 10).
- QR: **niet** gebouwd — geen pure-Rust QR-crate in het register (verzoek in `docs/coordination/generators.md`).

## Oracles
- Paneeloppervlak: `a·b − t·Σ(sleuflengtes) + t²·(hoeken waar twee sleuven samenvallen)`, onafhankelijk van de randwandeling.
- Code 128: checksums met de hand berekend (`(start + Σ positie·waarde) mod 103`); patronen uit de symbologietabel,
  gecontroleerd op structuurinvarianten. **Geen onafhankelijke decoder/scanner** gebruikt: de "benoemde leesproef"
  (E11) is een handmatige acceptatie op materiaal en staat open.
