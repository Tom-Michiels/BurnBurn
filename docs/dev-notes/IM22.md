## Oracles
- Paneeloppervlak: `a·b − t·Σ(sleuflengtes) + t²·(hoeken waar twee sleuven samenvallen)`, onafhankelijk van de randwandeling.
- Code 128: checksums met de hand berekend (`(start + Σ positie·waarde) mod 103`); patronen uit de symbologietabel,
  gecontroleerd op structuurinvarianten. **Geen onafhankelijke decoder/scanner** gebruikt: de "benoemde leesproef"
  (E11) is een handmatige acceptatie op materiaal en staat open.

## W2-L5d barcodes

Pakket W2-L5d ("ontbrekende barcodes", research/lightburn/02-features.md §4, 06-dialoogcatalogus.md "Bar Code Properties"): alle 29 LightBurn-barcodetypen achter één API in `burnburn-generators::symbology` (`Symbology`, `SymbologyParams`, `encode_symbol`, `symbology_catalog`, `SymbolCapabilities`). Commando's: `export PATH="$HOME/.cargo/bin:$PATH" CARGO_TARGET_DIR=target/l5-barcode`.

### API-keuzes
- Fysieke maten zijn echte mm (`module_mm`, `min_module_mm` uit een benoemde leesproef, `height_mm` voor lineaire codes). Geen kerf. Origine linksonder in de stille zone, y omhoog (zoals `Barcode`/`QrSymbol`). Geometrie: één gesloten rechthoek per run donkere modules; identieke opeenvolgende rijen (PDF417-rijhoogte) worden één hogere rechthoek.
- Stille zone: `quiet_modules: None` = standaardminimum van het symbool, kleiner is `QuietZoneTooSmall` (nooit stil verbreed). Minima: QR 4, Micro QR/rMQR 2, DataMatrix 1, Aztec 0, PDF417 (+Compact) 2, MicroPDF417 1, EAN-13/ISBN 11, EAN-8 7, UPC-A/E 9, Code 128/93/Codabar/2 of 5/Plessey/VIN 10, markers 1.
- Fouten zijn getypeerd (`SymbolError`: `Unsupported{symbology,reason}`, `InvalidChar{ch,index}`, `CheckDigit{expected,found}`, `PayloadLength`, `InvalidPayload{rule}`, `UnknownAi`, `DataTooLong`, `QuietZoneTooSmall`, `EccStepUnavailable`, `InputModeUnavailable`, `ParamNotApplicable`, `MarkerId`, `Param(GenError)`, `Engine`). Niet-geïmplementeerde symbologieën geven `Unsupported`, nooit een gelijkend patroon.
- ECC is een index in de ladder van het symbool (`SymbolCapabilities::ecc_steps`, UI-slider): QR L/M/Q/H (default L, zoals de LightBurn-slider "Low"), Micro QR Detection(M1)/L/M/Q (default L), rMQR M/H, PDF417 level 0..8 (default 2); Aztec/DataMatrix/MicroPDF417 hebben vaste correctie.
- Input mode (`Data`/`Unicode`/`Gs1`): `Data` = één byte per teken (U+0000..=U+00FF, daarboven `InvalidChar`), `Unicode` = UTF-8 (alleen QR, Micro QR en rMQR, dat ECI 26 schrijft bij niet-ASCII), `Gs1` = `(AI)waarde…` (alleen Code 128 GS1).
- GS1: eigen AI-tabel (alleen AI's met bevestigde lengte/tekenset; onbekende AI = `UnknownAi`), mod-10 controle voor AI 00/01/02/410-415, FNC1 alleen na elementen zonder vooraf gedefinieerde lengte (voorvoegsels 00-04, 11-20, 31-36, 41), max 48 datatekens.

### Handmatig / onbevestigd
- **Geen fysieke leesproef** op laser/materiaal en geen ISO/IEC 15416/15415-printkwaliteit: `min_module_mm` blijft de invoer van een benoemde leesproef (E11).
- Markers zijn niet met een beelddetector (AprilTag/ArUco) uitgelezen — alleen tegen de woordenboekbronnen; de geometrie volgt de definitie, de pose-oriëntatie (AprilTag officieel) is niet met een camera bevestigd.
- Plessey, 2 of 5 en MicroPDF417 zijn alleen met een tweede encoder (BWIPP-port) vergeleken, niet met een lezer.
- Windows en overige platformen: niet gedraaid (pure Rust, geen platformcode).
- Open voor de lead/UI: betekenis "2 of 5"; mapping "ArUco MIP 36h11"; Han Xin en Grid Matrix wachten op een onafhankelijke lezer; GS1-modus voor DataMatrix/QR/Aztec (FNC1-marker) ontbreekt; EAN/UPC add-ons (2/5 cijfers) niet aangeboden; Code 93 zonder full-ASCII; ECC-aanwijzingen per type in `SymbolCapabilities`.
