# IM07 Gedeeld GPU-canvas (`burnburn-render`) — eerste ronde

Status: scenevertaling en offscreen Metal-rendering groen op macOS 27 arm64 (Apple-GPU, wgpu 30.0.1, backend Metal).
DX12/Windows: **onbevestigd** (geen runner). Linux-CI: geen backend gecompileerd → GPU-test meldt `SKIPPED`, telt niet als geslaagd.

Commando's: `export PATH="$HOME/.cargo/bin:$PATH"; CARGO_TARGET_DIR=target/gui cargo test -p burnburn-render …`

## Keuzes
- **wgpu 30.0.1** (MSRV 1.87, werkt met 1.99.1), `default-features = false`, `std`+`wgsl`, per target `metal`/`dx12` (ADR 0003).
- **Tessellatie: eigen minimale** (`src/tess.rs`): gevulde as-uitgelijnde rechthoek = 2 driehoeken; stroke = één quad per
  segment met vierkante kappen (halve breedte voorbij elk eind), geen joins. Translucente strokes blenden dubbel in hoeken.
  Vervanging door `lyon` (ADR 0003) is een refactor onder dezelfde tests.
- **f64 → f32**: projectie in f64 relatief aan de camera; pas viewportrelatieve device-pixels worden f32.
- **Doelformaat**: offscreen `Rgba8Unorm`, op het scherm het eerste niet-sRGB-surfaceformaat (Bgra8Unorm), zodat
  kleuren in beide gelijk betekenen. Afwijking van ADR 0003 (`Rgba8UnormSrgb`) — voorgelegd in `docs/coordination/gui.md`.
- Scene-invoer `SceneInput/SceneItem/SceneShape` is tijdelijk (geometry had nog geen publieke types); zie DR-02.

# Fase B (18-10-2026) — DR-02, lyon, surface/device-verlies

- DR-02: render hangt af van `burnburn-editor` + `-geometry` + `-types`; eigen `Camera`/`Viewport`/`SceneInput` weg
  (camera-tests verhuisden naar `editor::view`, User-flow). `build_packet(&SceneSnapshot, &Theme) -> RenderPacket`:
  paden geflattened met `DisplayTolerance` = 0,25 device-px in mm, projectie in `f64` relatief aan de camera,
  rollen → `Theme`, raster (1-2-5, px-uitgelijnde hairlines, max 1000 lijnen), overlays (selectiekader, rubberband,
  dragpreview, handles/nodes/snap/issue-markers). `Primitive::FillRect` → `Fill { contours_px }` (even-odd).
- Tessellatie: `lyon_tessellation` 1.0.22 (fill even-odd, stroke square cap + miter) i.p.v. eigen quads.
- `surface::SurfaceCanvas` (gedeeld door Mac/Windows): host levert alleen een surface-factory (unsafe in host);
  `recovery(status, device_lost)`: Lost → nieuwe surface, device lost → nieuw device + surface, Outdated → reconfigure,
  Occluded/Timeout → overslaan (host tekent opnieuw bij occlusion-wissel). `GpuContext::is_lost()` via
  `set_device_lost_callback`; `render_offscreen` → `GpuError::DeviceLost`.
